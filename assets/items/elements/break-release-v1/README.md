# 원소 오브젝트 파손과 구슬 방출 · v1

2026-11-06 사용자 요청으로 제작했습니다. 기존 항아리·장작·바람개비·돌무더기·전지를 직접 먹는 대신, 공격으로 점차 파손시키고 방출된 원소 구슬을 먹습니다.

- 물: 항아리 균열과 테두리 파손 → 도자기 파편 → 물 구슬
- 불: 불꽃 크기 감소 → 잔불과 연기 → 불 구슬
- 바람: 날개 끝 손상 → 갈라짐·찢어짐 → 날개 분리와 바람 구슬
- 흙: 균열 증가 → 조각 분리·붕괴 → 흙 구슬
- 번개: 전지 외피 균열 → 외피·단자 분리 → 번개 구슬

## 미리보기

`preview.html`은 이미지가 포함된 오프라인 재생기입니다. 자동 재생·정지·속도 조절과 종류별 한 번 공격 버튼을 제공합니다. 기본 상태에서 공격 세 번은 누적 손상, 네 번째는 파괴·방출로 시연합니다. 이 타격 횟수와 재생 시간은 비교용 제안이며 게임 밸런스로 확정하지 않았습니다.

`element-destruction.gif`는 다섯 종류를 동시에 보여 줍니다. `*-break.gif`는 개별 애니메이션입니다. 비교용 재생은 반복되며 실제 파괴 동작은 한 번만 실행하고 구슬을 남기는 용도입니다.

## 에셋

`sprites/*-break.png`는 256×256px 프레임 8개를 가로로 배치한 투명 PNG입니다. 좌표와 프레임별 시간은 `animations.json`에 있습니다. 앞 네 프레임은 타격 누적 상태, 뒤 네 프레임은 마지막 타격 후 파괴·방출입니다. 실제 게임에서는 누적 상태를 각 타격 전까지 유지하며, 오브젝트가 스스로 손상되도록 재생하지 않습니다.

`source/`는 내장 image_gen으로 새로 생성한 원화입니다. 기존 원소 오브젝트와 승인된 구슬 이미지를 참고했습니다. 불 시트의 배경은 같은 도구로 투명화했습니다. 코드로는 생성된 규칙 격자의 프레임 분할·패킹·재생만 수행했습니다. 최종 생성 프롬프트는 `generation.json`에 저장했습니다.

현재는 애니메이션 시안입니다. Python/pico2d의 피격·오브젝트 체력·충돌·구슬 생성·F 섭취 판정과 연결하지 않았습니다. 원소 오브젝트의 체력, 필요한 타격 수, 드롭 개수, 구슬 생존 시간, 재생성 및 엄폐 소멸 시점 등의 상세 수치는 미확정입니다.
