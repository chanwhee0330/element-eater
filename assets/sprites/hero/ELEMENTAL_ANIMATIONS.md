# 다섯 원소 캐릭터 · 네 가지 애니메이션

2026-11-06 사용자 요청으로 물·불·바람·흙·번개에 각각 대기·걷기·기본 공격·원소 구슬 먹기를 제작했습니다.

**5원소 × 4동작 = 20종 시트. 각 시트는 4방향 × 8프레임으로 총 640프레임입니다.** 기존 무속성 4종 128프레임까지 포함하면 캐릭터 전체는 24종 768프레임입니다.

| 원소 | 몸색과 구분 특징 |
| --- | --- |
| 물 | 파랑 몸, 물방울 귀와 물빛 표면 |
| 불 | 주황·붉은 몸, 불꽃 귀 |
| 바람 | 연두 몸, 뒤로 휘는 긴 잎 귀 |
| 흙 | 황갈색 몸, 바위 귀와 작은 돌 판 |
| 번개 | 노랑 몸, 짧은 지그재그 번개 귀 |

## 규격

- PNG 하나당 1024×512px, 128×128px 칸, 8열×4행.
- 행 순서는 아래(정면)·왼쪽·오른쪽·위(뒷면)입니다.
- 발밑 기준점 (64, 114), 권장 표시 배율 0.5입니다.
- 대기 4fps·반복, 걷기 10fps·반복, 기본 공격 12fps·단발, 구슬 먹기 12fps·단발입니다.
- 공격·먹기의 시작과 끝은 같은 원소·방향의 대기 0번과 픽셀이 완전히 같습니다. 대기·공격·먹기의 발 하단도 고정해 동작 전환 후 위치가 바뀌지 않습니다. 걷기는 발의 보행 동작을 유지합니다.
- 모든 방향·동작에서 해당 원소의 몸색과 귀 특징을 유지합니다. 뒷모습에 얼굴을 넣거나 다른 색으로 칠하지 않았습니다.
- 공격의 발사체와 먹는 구슬은 캐릭터 PNG와 분리했습니다. 위쪽은 캐릭터 뒤에 그립니다.
- 기본 공격은 Space 동작입니다. 물의 자가 치유, 불의 화상, 바람의 강한 넉백, 흙벽, 번개 연쇄 공격 같은 R 고유 능력의 새 시트를 만든 것은 아닙니다.

## 파일

- `sprites/<원소>/hero-<원소>-<idle|walk|attack|ingest>.png`와 같은 이름의 JSON: 20쌍의 아틀라스.
- `all-elements-front.gif`: 다섯 원소 × 네 동작 정면 비교.
- `previews/<원소>-four-states.gif`: 각 원소의 4방향 × 4동작 비교.
- `preview.html`: 원소·방향 선택, 일시정지, 재생과 발 위치 표시를 지원하는 오프라인 재생기. 폴더 구조를 유지해서 열어야 합니다.
- `catalog.json`: 다섯 원소의 이미지 경로·속도·반복·입 위치.
- `source/`: 내장 image_gen으로 만든 원화 20종. 최종 프롬프트는 `generation.json`입니다.

각 원소의 기본 대기 모습을 먼저 만든 뒤 이를 해당 원소의 세 가지 다른 동작에 참조했습니다. 코드로는 원화 자르기·균일 배율·발 정렬·대기 시작/끝 연결·시트 패킹·미리보기 합성을 수행했습니다. 기존 무속성 원화와 PNG는 수정하지 않았습니다.

기본 공격의 3번 프레임 발사, 섭취의 4번 프레임 이벤트는 기존 애니메이션과 맞춘 초기 시안입니다. 실제 전투·인벤토리·원소 전환과 Python/pico2d 본게임은 아직 연결하지 않았습니다.
