# 1~5번 방 원소 테마 개편

1~5번 방에서는 적을 모두 처치한 뒤 출구에 접근하면 구슬 섭취 컷신이 재생된다. 배운 원소는 영구 보유한다. 출구를 열기 위한 환경 퍼즐은 6~9번 방에 배치한다.

| 방 | 지형과 전투 | 보상 |
| --- | --- | --- |
| 1. 물의 수로 신전 | 수로와 징검다리, 무속성 적 | 물 |
| 2. 불의 화로 사원 | 화로와 용암 수로 사이, 불 적 | 불 |
| 3. 바람의 공중 회랑 | 지그재그 석교와 공중 섬, 바람 적 | 바람 |
| 4. 흙의 암굴 제단 | 채석장 돌기둥과 고정 석재, 흙 적 | 흙 |
| 5. 번개의 전력 성소 | 방전 코일과 석재 엄폐물, 번개 적 | 번개 |

각 방에 근접형과 원거리형을 하나씩 둔다. 화로와 코일은 시각 효과다. 바람 회랑의 다리와 섬 경계는 돌벽으로 막고 입구의 열린 가장자리에서는 떨어질 수 있다. 이전 1~5번 방 저장은 해당 방 입구에서 재개하며 체력과 원소 해금을 이어간다.
