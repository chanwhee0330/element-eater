# 기본 공격 투사체 6종 · v1

무속성과 물·불·바람·흙·번개의 **Space 기본 공격 비행 애니메이션**입니다. 기존 무속성 효과 `assets/effects/neutral/`는 보존합니다. 새 원화는 내장 `image_gen`으로 제작했고, 현재 캐릭터와 어울리는 부드러운 채색·짙은 윤곽을 사용합니다.

| 종류 | 형태·움직임 |
| --- | --- |
| 무속성 | 아이보리 충격탄과 크림색 압축 공기 꼬리 |
| 물 | 푸른 물방울, 흐르는 물결과 작은 물방울 |
| 불 | 뜨거운 불씨, 일렁이는 주황 불꽃과 작은 불티 |
| 바람 | 연두색 압축 공기와 휘도는 소용돌이 |
| 흙 | 각진 황갈색 돌, 먼지와 작은 돌 파편 |
| 번개 | 노란 지그재그 전기탄, 보랏빛 가지와 전기 불꽃 |

## 파일·규격

- `<element>-flight.png` / 같은 이름의 JSON: 원소별 1쌍, 총 6쌍·192프레임.
- 160×160px 칸, 8열×4행, 전체 1280×640px. 행은 아래·왼쪽·오른쪽·위, 열은 비행 순서입니다.
- 공통 투사체 본체 기준점은 칸 내부 (80,80)입니다. 실제 충돌 크기를 뜻하지 않습니다. `pico2dClip`은 이미지 아래쪽 원점 기준입니다.
- 12fps 반복. 표시 배율 0.25, 캐릭터 대비 배율 0.5, 공격 3번 프레임·0.25초 발사는 **시각 시안용 초기값**입니다.
- 생성 원화의 오른쪽 불투명 본체로 프레임을 등록합니다. 원소별로 한 배율을 공유하며 움직이는 꼬리·입자 최대 범위로 프레임마다 크기를 바꾸지 않습니다. 상하좌우는 같은 동작을 정확히 90도 단위로 회전합니다.
- 원본의 투명도와 반투명 효과를 보존합니다. 색 배경이나 체크무늬를 굽지 않습니다.
- `source/`: 투명 배경 생성 원화 6종. 원본은 보존하고 시트만 재생성합니다.
- [최종 프롬프트](../../../prompts/hero-basic-projectiles-v1.json): 내장 도구, 스타일 참조, 원소별 전체 프롬프트.

저장소 루트에서 `python tools/build_basic_projectiles.py`로 재생성합니다(Pillow·NumPy 필요). 내보낸 PNG의 192프레임 변화·투명도·테두리·방향 회전과 JSON 해시를 검사하며, [독립 HTML](../../../../outputs/previews/basic-projectiles/preview.html)·GIF 및 기존 캐릭터 재생기 두 사본과 모아보기를 갱신합니다. HTML은 이미지와 움직이는 대체 GIF를 내장해 단독으로 열 수 있습니다.

## 게임 규칙과의 구분

이 투사체는 먹는 원소 구슬이 아닙니다. 물의 자가 치유, 불 화상, 바람 강한 넉백, 흙벽, 번개 다중 연쇄는 R 고유 능력으로 별도 유지합니다. 이 시트 제작으로 Space에 R 효과를 추가하지 않습니다.

원소 Space 공격은 약점이 맞는 적만 공격하며, 같은 원소를 포함한 나머지는 피해·공격 효과 0입니다. 무속성 기본 공격은 적 원소와 관계없는 낮은 피해와 약한 넉백 예외를 유지합니다. 원소 보유량을 소모하지 않으며, 이미 발사된 투사체는 발사 당시 원소·방향을 유지해야 합니다. 원소 오브젝트의 3타/약점 1타 규칙은 적 전투 상성 필터와 별도입니다.

캐릭터와의 발사 연출을 HTML/GIF에 연결한 상태입니다. Python/pico2d 본게임의 발사·이동·벽/적 충돌·상성·피해·수명 처리는 아직 구현하지 않았습니다.
