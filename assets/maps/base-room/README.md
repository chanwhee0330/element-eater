# 기본 맵 · 30×30

같은 크기에 구멍·내부 벽·가시를 배치한 [장애물 예시 맵](../obstacle-room/README.md)도 준비했습니다. 이 기본 맵은 빈 방 비교 기준으로 유지합니다.

[구멍·벽·가시 장애물 기획](../../../docs/design/OBSTACLES_AND_HAZARDS.md)을 추가했습니다. 이 폴더의 기존 맵과 미리보기는 빈 방의 크기 비교 기준이며, 내부 위험 지형·추락·가시 피해 판정은 아직 구현하지 않았습니다.

사용자 요청에 따라 플레이어 크기를 1로 보고 만든 첫 크기 비교 맵입니다. 전체 맵은 **30×30칸**, 한 칸은 제작 해상도 **64×64px**이며 배경 PNG는 **1920×1920px**입니다. 외곽 1칸은 벽이므로 내부 바닥은 28×28칸입니다. 내부 장애물 없이 크기를 먼저 확인합니다.

플레이어의 기준 크기 1은 **현재 무속성 idle 정면 0번의 잎부터 발끝까지 보이는 높이**입니다. 투명 여백이 있는 128px 원본 칸 전체를 1로 잡지 않습니다. 같은 배율을 대기·걷기와 네 방향에 공통 적용해 원본 동작을 유지합니다. 비교용 1×1 사각형과 플레이어 중심을 표시합니다.

- [맵 배경 PNG](base-room.png): 측정선·플레이어가 없는 게임용 배경.
- [타일·충돌·배율·시작점 JSON](base-room.json): 30행×30열, 벽 타일 ID 3, 플레이어 중심 (15, 15).
- [타일 아틀라스](base-room-tiles.png): 64px 칸의 2×2 시트. 0 일반 바닥 / 1 금 간 바닥 / 2 이끼 바닥 / 3 벽.
- [플레이어를 배치한 비교 PNG](../../../outputs/previews/base-room/base-room-scale-preview.png).
- [움직이는 크기 비교](../../../outputs/previews/base-room/base-room-preview.html): 서버 없이 열고 맵 클릭 후 WASD/방향키로 이동. 대기·걷기 4방향, 대각선 속도 보정, 외곽 벽 충돌, 눈금과 1칸 크기 표시, 중앙 복귀 지원.

이동 속도 5칸/초는 미확정 미리보기 시험값입니다. 이 자료는 맵 크기 비교용이며 적·전투·원소 섭취·퍼즐·방 전환을 구현한 본게임이 아닙니다. Python/pico2d 본게임 개발 도구는 기존 계획을 유지합니다.

## 다시 만들기

Pillow가 있는 Python 환경에서 저장소 루트에서 실행합니다.

```sh
python tools/build_base_room.py
```

[source/recipe.json](source/recipe.json)의 크기·벽 두께·시드를 읽어 타일맵을 결정적으로 배치합니다. 원화는 [source/tiles-source.png](source/tiles-source.png), 내장 image_gen의 [제작 프롬프트](../../prompts/base-room-tiles.md)는 별도로 보관합니다. 생성 도구는 원화를 사각 분리·리사이즈하고 기존 플레이어 PNG를 배치합니다. 미리보기 동작 원본은 `tools/base_room_preview.js`, 화면 틀은 `tools/base_room_preview.html`입니다.

크기 30×30은 현재 기본 비교 맵에 대한 요청이며 모든 방의 최종 크기로 확정한 것은 아닙니다.
