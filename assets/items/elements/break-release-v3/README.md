# 손상 상태 대기 애니메이션 수정 · v3

## 추가 수정: 재생 중단과 타격 후 위치

첫 requestAnimationFrame 타임스탬프가 스크립트 시작 시간보다 앞서는 경우 음수 dt가 전달되어 전체 재생이 종료되는 오류를 수정했습니다. 첫 프레임은 dt=0이며, 이후에도 음수·비정상 값이 시뮬레이션에 전달되지 않습니다.

타격 순간의 130ms 흔들림은 유지합니다. 흔들림 종료 후 정상·손상 1·손상 2의 본체가 같은 자리로 돌아오도록 원본 정상 대기 시트의 고정된 바닥 접점에 맞춰 손상 시트를 정렬했습니다. 불꽃·물방울·날개 끝처럼 움직이는 부분을 기준으로 다시 중심을 잡지 않습니다. 각 손상 단계의 모든 8프레임에 같은 정렬 변환을 적용하고, 바닥 접점의 y가 정상 상태와 정확히 같으며 가로 기준점은 1.5px 이내인 것을 검사합니다. 구슬 크기는 그대로 96px입니다.

정렬 기준·변환은 `animations.json`의 `registration`에 있습니다. 바람의 받침대·중앙 허브와 전지의 바닥 부분도 움직임 마스크에서 보호합니다.

v2의 렌더러는 정상 상태에서만 대기 애니메이션을 그리고, 손상 1·2단계에서는 정지 이미지 한 장을 그렸습니다. 공격 뒤 움직임이 없어지던 원인입니다.

v3는 다섯 오브젝트 각각에 손상 1·2단계 전용 8프레임 반복 시트를 추가하고 해당 상태에서 계속 재생합니다.

| 오브젝트 | 손상 상태에서도 반복되는 동작 |
| --- | --- |
| 물 항아리 | 수면 잔물결, 심한 손상 시 새는 물방울 |
| 불 장작 | 단계별 크기를 유지하는 불꽃과 연기 |
| 바람개비 | 찢어진 날개의 회전 |
| 돌무더기 | 왼쪽 앞 작은 돌의 움직임 |
| 전지 | 중앙 번개 밝기 변화와 외부 전기 효과 |

정상 상태·손상 1·손상 2는 각각 별도의 대기 동작입니다. 타격으로만 내구도가 바뀝니다. 불일치 3회/약점 1회 파괴, 방출 후 구슬 유지, 5종 동일 96px 구슬 규격은 유지합니다. 첫째·둘째 공격 뒤에는 다음 공격까지 해당 손상 상태의 동작이 무기한 반복됩니다.

움직임 원화는 내장 image_gen으로 만들었습니다. 최종 프롬프트는 `generation.json`, 생성된 4×4 원화는 `source/`에 있습니다. 각 원화의 앞 8칸이 손상 1, 뒤 8칸이 손상 2입니다. 패킹 시 움직임 영역을 분리하고 나머지 본체를 첫 프레임으로 고정했습니다. `*-motion-mask.png`의 흰 영역만 움직임을 허용하며 검은 영역은 루프 내 RGBA 값이 모두 같습니다.

- `preview.html`: 이미지가 포함된 오프라인 직접 공격 미리보기. 공격 원소·약점·개별 공격·시연·일시정지를 지원합니다.
- `damaged-idle-loops.gif`: 위쪽 1회 피격 후, 아래쪽 2회 피격 후의 반복 동작. 기다려도 동작이 사라지거나 손상이 진행되지 않습니다.
- `sprites/*-damaged1.png`, `*-damaged2.png`: 각각 256px 8프레임을 가로로 패킹한 투명 시트입니다.
- `animations.json`: 상태별 시트, 프레임 수, fps, 반복·상태 유지 규칙을 기록합니다.
- `state-machine.mjs`: 이전 버전의 3타/약점 1타 상태 전이입니다. 현재 수정은 이 상태에 맞는 반복 애니메이션을 연결하는 렌더러 수정입니다.

Python/pico2d 본게임은 아직 연동하지 않았습니다.
