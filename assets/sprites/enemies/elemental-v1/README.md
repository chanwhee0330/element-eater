# 무속성·5원소 일반 적 · 고정 몸통 애니메이션 v1

무속성·물·불·바람·흙·번개 각각에 **근접형(추격형)·원거리형(사격형)** 외형을 적용했습니다. 내장 `image_gen`으로 부품 원화 12종을 제작하고 같은 몸통에 관절 부품을 조립해 대기·이동·공격 시트를 만듭니다. 2026-11-10 현재 무속성은 1/2번 방, 불은 2번 방의 Python/pico2d AI·전투에 연결했고 다른 원소는 에셋만 있습니다.

| 유형 | 외형 구분 | 동작 |
| --- | --- | --- |
| 근접형 | 두 눈, 넓은 눈썹 장갑, 큰 주먹과 튼튼한 부츠 | 대기 중 팔·발광 변화, 발 교대 이동, 주먹을 내미는 접촉 공격 연출 |
| 원거리형 | 외눈, 원형 발사구, 가는 팔과 작은 부츠 | 대기 중 팔·발광 변화, 발 교대 이동, 팔 지지·충전 후 발사 연출 |

원소는 물의 파란 장갑·물방울 장식, 불의 적갈색 장갑·불꽃, 바람의 초록 장갑·휘는 잎과 공기 장식, 흙의 황갈색 장갑·돌 결정, 번개의 남보라 장갑·노란 번개 장식으로 구분합니다. 기존 컨셉 `assets/concepts/gameplay-element-matchup.png`의 소형 갑주 정령을 참고했으며 디자인은 시안입니다.

## 무속성 추가

무속성은 회색·은색 갑주, 아이보리 눈과 발광으로 구분하며 원소 머리 장식이 없습니다. 여섯 번째 원소가 아닙니다. `neutral/`의 6개 시트·192프레임을 같은 고정 몸통 빌더로 만들었습니다. [무속성 원화 생성 프롬프트](../../../prompts/neutral-enemy-rigs-v1.json)를 보관합니다. 최신 사용자 요청대로 무속성 적은 무속성·다섯 원소 공격 모두에 큰 피해(15는 시험값)를 받습니다. 원소 적의 상성 차단과 무속성 기본 공격의 약한 넉백은 유지합니다.

## 고정 규칙

- 각 원소·유형·방향의 **몸통 PNG를 모든 동작·프레임에서 그대로 재사용**합니다. 몸통을 프레임마다 이동·회전·확대하거나 알파 외곽에 맞춰 재중심화하지 않습니다.
- 몸통 등록 목표는 중심 (80,86), 가로·세로 (72,64), 고정 루트는 (80,138)입니다. 방향별 원화 등록은 한 번만 적용합니다. 원소 머리 장식도 몸통에 고정합니다.
- 몸통 알파는 모든 프레임에서 같습니다. 빛나는 부분은 알파를 바꾸지 않고 RGB 밝기만 조절합니다. 팔·발이 가리지 않는 몸통 보호 영역은 최종 PNG에서도 RGBA 픽셀이 정확히 같습니다.
- 팔·발은 원래 비율을 유지하며 관절 회전·이동만 합니다. 걷는 발과 공격 중 뻗는 팔 때문에 **전체 포즈 외곽**은 달라질 수 있지만, 이를 기준으로 캐릭터 크기를 다시 조절하지 않습니다.
- 부츠 윗부분에서 만든 고정 크기의 다리 연결 부품으로 몸통과 발을 연결합니다. 몸통을 직사각형 발 밴드로 덮어쓰거나 포즈를 자르지 않습니다.
- 공격 처음·마지막은 해당 방향 대기 0번과 완전히 같습니다. 재생 중 빈 프레임으로 사라지지 않습니다.

## 파일과 재생

- `<원소>/<유형>/enemy-<원소>-<유형>-<idle|walk|attack>.png`와 같은 이름의 JSON: **36쌍·1,152프레임**.
- 시트 1280×640px, 160×160px 칸, 8열×4행. 행은 아래·왼쪽·오른쪽·위, 열은 시간 순서입니다. `pico2dClip`은 아래쪽 원점 좌표입니다.
- 대기 6fps·이동 10fps 반복, 공격 12fps 단발. 표시 배율 0.5·공격 이벤트 3번 프레임은 초기 시안 값입니다.
- `source/`: 원화 12종. 각 원화는 4방향 × 몸통·왼팔·오른팔·왼발·오른발의 5개 부품 행입니다. 원화의 투명 행 간격을 측정해 부품을 잘라 내며 단순 5등분으로 몸통을 자르지 않습니다.
- `<원소>/<유형>/rig/`: 등록된 몸통·팔다리 PNG, 발광 마스크, 보호 영역 마스크, 방향별 등록 기록. 원화는 보존하고 최종 출력만 다시 만듭니다.
- [전체 생성 프롬프트](../../../prompts/elemental-enemy-rigs-v1.json): 내장 도구·스타일 참조·원소별/유형별 프롬프트 10개.

저장소 루트에서 실행합니다(Pillow·NumPy 필요).

```powershell
python tools/build_elemental_enemies.py
python tools/build_elemental_enemies.py --validate-only
```

빌더는 최종 PNG 1,152프레임에서 보호 영역 픽셀, 실제 이동·대기·공격 변화, 발 교대, 공격/대기 연결, 테두리 잘림, PNG/JSON 해시를 검사합니다. 보호 영역은 방향별 최소 1,000픽셀 이상이며 팔·발이 지나가는 모든 영역과 발광 영역을 제외합니다. 메타데이터의 중심값만 확인하는 검사가 아닙니다.

[독립 HTML](../../../../outputs/previews/elemental-enemies/preview.html)은 36개 적 시트·6개 별도 투사체·GIF 대체 화면 2개를 내장합니다. 원소·방향·두 유형·세 동작 비교, 전체 12종 보기, 일시정지·속도·프레임 넘기기·프레임 슬라이더와 고정 기준선을 지원합니다. 스크립트가 실행되지 않아도 GIF 대체 화면은 보입니다.

## 기존 기획과 연결할 부분

두 행동형의 외형 변형 12종이며, AI 12종을 구현한 것이 아닙니다. 근접형의 기존 접촉 공격과 원거리형의 제자리 예고 후 사격을 유지합니다. 원거리형 이동 시트는 요청한 에셋으로 준비했으며, 이 제작으로 AI 이동 규칙을 변경하지 않습니다. HTML 발사 시연은 기존 `assets/effects/basic-projectiles/v1/`의 같은 원소 투사체를 별도 레이어로 사용합니다.

적 상성 불일치·같은 원소 공격의 피해/공격 효과 차단, 무속성 낮은 피해·약한 넉백 예외를 유지합니다. 실제 추격·사격 AI, 발사·충돌·피해·처치 판정과 스테이지 배치는 별도 구현 단계입니다.
