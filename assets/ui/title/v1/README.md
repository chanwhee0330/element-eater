# 타이틀 화면 이미지 시안 v1

사용자 요청에 따라 시작 화면에 사용할 이미지부터 제작했습니다. 아이보리 몸·초록 잎 귀의 주인공이 파괴 후 방출된 원소 구슬을 먹는 장면으로 게임의 특징을 보여줍니다. 물·불·바람·흙·번개의 다섯 구슬을 색과 내부 형태로 구분하며 원천 오브젝트를 직접 먹지는 않습니다.

- `title-screen-v1.png`: 상단 영문 게임 로고/한국어 제목, 중앙 섭취 장면, 하단 메뉴용 빈 공간을 포함한 원본
- [공유 이미지](../../../../outputs/previews/title-screen/title-screen-v1.png)
- [전체 프롬프트](../../../prompts/title-screen-v1.json): 내장 image_gen과 기존 주인공/원소/게임 화면 참조 사용

기존 게임 창 1000×900의 비율을 기준으로 구성했습니다. 로고는 이미지에 포함되어 있습니다. 현재 `main.py`의 실제 타이틀에 연결했으며 하단 버튼은 코드로 별도 렌더링합니다. 왼쪽 이어하기/가운데 새게임 시작/오른쪽 종료 순서이고, 저장이 없으면 이어하기를 비활성화하며 저장이 있으면 아래에 스테이지 번호를 표시합니다.
