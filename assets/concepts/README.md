# 컨셉 이미지

이 프로젝트 대화에서 AI 이미지 생성으로 준비한 기획용 이미지입니다. 실제 게임 구현 화면이나 완성된 애니메이션 시트가 아닙니다.

| 파일 | 용도 |
| --- | --- |
| character-cover.png | 주인공과 다섯 원소의 표지 컨셉 |
| element-items.png | 원소를 얻는 먹이 5종 |
| hero-element-forms.png | 물·불·바람·흙·번개에 따른 몸 색과 외형 변화 |
| gameplay-element-matchup.png | 파란 물 주인공이 붉은 불 적을 공격하는 최신 컨셉 |
| earth-form-cover-example.png | 흙 섭취 전후의 외형과 엄폐 지형 변화 |
| gameplay-concept.png | 이전 플레이 구상, 적 원소와 상성 추가 전 |
| earth-cover-example.png | 이전 엄폐 비교, 주인공 외형 변화 추가 전 |

게임에 넣을 때는 크기, 투명 배경, 충돌 영역과 애니메이션 프레임을 정리합니다. 기존 에셋을 추가로 사용하면 출처와 이용 조건을 기록합니다.

최신 세 이미지는 내장 이미지 생성 도구로 제작했습니다. [생성 프롬프트](../../docs/art/element-visual-prompts.md)에 참조 이미지와 요청을 기록했습니다.
