# 게임 효과음 출처

적 발걸음, 함정과 장치, 섭취, 보스 동작 및 장치 반복음에 추가한 효과음과 0번 방 연기음 25종은 프로젝트용으로 합성한 22.05 kHz 모노 PCM WAV입니다.

아래 원본은 모두 [CC0 1.0](https://creativecommons.org/publicdomain/zero/1.0/)입니다. 입력과 타격에 맞춰 필요한 부분을 잘라 내고, 길이와 음량을 조정해 44.1 kHz 모노 PCM WAV로 변환했습니다.

플레이어 공격음(`player-attack.wav`)과 적 일반 피격음(`enemy-hit.wav`)은 프로젝트용으로 합성했습니다.
