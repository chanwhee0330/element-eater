# 첫 번째 방 배치 시안

## 맵 바깥 심연 배경

사용자가 뜻한 검은 공간을 안개와 멀리 아래로 떨어지는 절벽 원경으로 꾸몄습니다. 최신 v2는 바닥과 색감이 따로 논다는 피드백에 따라 청록 기를 제거하고 저채도 회갈색·차콜 톤으로 맞췄습니다. 걸을 수 있는 바닥보다 어둡게 두며, 기존 바닥 장식과 낭떠러지 경계를 유지합니다. 새로운 이동 가능 지형이나 충돌체는 아닙니다.

- `source/abyss-source-v2.png`: 현재 내장 image_gen 색감 보정 원본. 프롬프트는 `assets/prompts/room-01-abyss-v2.json`(저장소 루트 기준). 이전 청록색 v1도 보존
- `source/backdrop.json`: 1000×900 화면·지도 위치·표시 배율 설정
- `room-01-backdrop.png`: 게임 창 전체 배경. 같은 그림의 해당 위치를 `room-01.png` 속 허공으로 잘라 여백과 낭떠러지가 이어짐

기존 빌더로 재생성하며, 게임은 `backdropImage`를 읽어 지형보다 먼저 그립니다. 정적 배경이며 게임을 다시 실행하면 적용됩니다.

## 배경 장식

기존 돌바닥에 이끼·짧은 풀·작은 돌조각과 낡은 원형 바닥 문양을 조금 추가했습니다. 시작 섬과 위쪽 공간에는 문양, 가장자리에는 소량의 자연 장식을 배치하며 연결로 중앙과 가시·벽·절벽 경계는 판독하기 쉽게 유지합니다. 장식은 모두 배경이며 충돌·피해·섭취 대상이 아닙니다. 타일/스폰/추격 조건/출구와 전투 수치는 바꾸지 않았습니다.

- `source/decor-atlas-v1.png`: 내장 image_gen으로 만든 투명 2×2 원본 아틀라스
- `source/decorations.json`: 장식 종류·크기·투명도·20개 위치를 수정하는 배치 원본
- `../../../assets/prompts/room-01-decor-v1.json`: 사용한 전체 프롬프트와 도구/참조 정보
- `../../../tools/room_01_decor.py`: PNG 준비·바닥 영역 합성. 기존 `python tools/build_room_01_preview.py`로 함께 재생성

최종 게임은 합성된 `room-01.png` 하나를 읽으므로 새 실행 의존성이나 추가 충돌 처리가 없습니다. 켜 둔 게임은 다시 실행해야 새 배경이 보입니다.

## Python/pico2d 첫 방 실행

현재 지도는 실제 Python/pico2d 첫 방에도 연결했습니다. 저장소 루트에서 의존성 설치 후 `python main.py`로 실행합니다. [설치 안내](../../../docs/guides/LAPTOP_SETUP.md) · [실제 시작 화면](../../../outputs/previews/room-01/python-start.png) · [추격 화면](../../../outputs/previews/room-01/python-chase.png).

WASD 이동·Space 무속성 탄환·고정 피벗 대기/걷기/공격·벽 충돌·큰 구역 진입 추격·근접 예고 공격/원거리 제자리 사격·체력/피격/넉백/처치·적 HP바/게임 HUD·첫 방 출구/클리어·Esc 메뉴를 구현했습니다. 적 전멸 후 출구에 도달하면 첫 방 클리어입니다. [실제 전투 화면](../../../outputs/previews/room-01/python-combat.png). 낙하 복귀/가시 점멸은 피해 없는 시안이며 원소·다른 방 진행은 아직 없습니다. 아래 HTML 제작 당시의 ‘Python 미구현’ 기록은 이 항목으로 갱신합니다. 지도 재생성에는 Pillow, 게임 실행에는 pico2d만 필요합니다. 정확한 지형 정책·속도·치수·피해/체력 수치는 계속 초기안입니다.

## 최신 수정: 시작 섬과 진입 후 추격

사용자 그림에 따라 **20×22칸**으로 줄였습니다. 빨간 선 안쪽만 바닥으로 두고 바깥은 낭떠러지입니다. 아래 10×4칸 시작 섬에서 폭 2칸·길이 6칸의 길을 올라 16×9칸 큰 구역에 진입합니다. 길 양옆에는 바닥이 없습니다. 빗금 부분은 큰 구역 중앙 6×2칸 벽이며 기존 중앙 가시와 작은 엄폐 벽을 대체합니다. 가시는 시작 섬의 길 입구 양옆 2×1칸씩 남겼습니다. 치수·좌표·속도는 시안입니다. 아래 최초 배치 기록보다 이번 수정이 우선합니다.

- [최신 지도](../../../outputs/previews/room-01/room-01-layout.png)
- [단독 실행 HTML](../../../outputs/previews/room-01/preview.html): 이미지 전부 내장, WASD 이동, Esc 정지/방 재시작, `진입·추격 시연` 버튼
- 시작 루트 (10, 19.5), 근접 (5.5, 9.5)/(14.5, 9.5), 원거리 (5.5, 4.5)/(14.5, 4.5). 적은 모두 큰 구역에 있습니다.
- `aggroTrigger`: 큰 구역 x∈[2,18), y∈[2,11)에 플레이어 루트가 처음 진입하면 근접 2마리의 추격을 시작합니다. 시작 섬·연결로에서는 대기합니다. 진입 뒤 되돌아가도 추격을 유지하는 것은 초기안입니다.
- 근접 적은 벽·가시·낭떠러지를 피하는 바닥 길찾기를 사용합니다. 원거리는 현재 배치/대기만 표시합니다. 공격과 피해는 없습니다.
- 낭떠러지는 플레이어에게 벽처럼 막히지 않고 낙하 후 안전 위치 복귀를 시연합니다. 가시는 점멸만 합니다. 지형 피해 규칙을 확정하거나 구현한 것은 아닙니다.
- `room-01.png`는 1280×1408, PNG/JSON/아틀라스 상대 파일명 유지. 구멍 테두리를 칸마다 반복하지 않고 하나의 허공과 바닥 경계로 그립니다.

재생성: `python tools/build_room_01_preview.py` (Pillow). 검사: `node tools/validate_room_01_preview.cjs` (진입 전 대기, 진입 추격, 추격 유지, 벽 우회, 벽 충돌, 낙하 복귀, 잘못된 시간 간격 방어, 독립 HTML 문법).

HTML의 지도·이동·추격 시연만 구현했습니다. Python/pico2d 본게임·원거리 사격·공격·체력·피해·방 전환은 미구현입니다.
