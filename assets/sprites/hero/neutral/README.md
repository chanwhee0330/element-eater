# 기본 무속성 캐릭터 스프라이트

아이보리 몸, 초록 잎 귀, 큰 입과 작은 팔다리를 유지한 기본형입니다. 원소 변신 전 상태이며, 내장 이미지 생성 도구로 제작했습니다.

- `hero-neutral-walk.png`: 투명 배경 PNG 원본, 실제 크기 1254 × 1254px, 총 16프레임.
- 행 순서: 아래(정면) / 왼쪽 / 오른쪽 / 위(뒷면).
- 각 행은 걷기 4프레임입니다. 첫 번째 프레임은 대기 상태에도 사용할 수 있습니다.
- `hero-neutral-walk.json`: 프레임 영역, 방향별 애니메이션, 발밑 기준점과 pico2d 클리핑 좌표.
- [제작 기록과 생성 프롬프트](../../../prompts/hero-neutral-walk.md): 사용 도구와 참조 이미지.

## 사용 방법

생성 결과가 1254px이므로 가로·세로를 정수 4등분한 313px로 고정해서 읽지 않습니다. JSON에 실제 프레임별 좌표를 기록했습니다. PNG는 생성된 투명도와 픽셀을 그대로 보존했습니다.

`frame`은 왼쪽 위 기준 좌표이고, `pico2dClip`은 왼쪽 아래 기준 좌표입니다. pico2d의 `clip_draw(left, bottom, width, height, cx, cy, draw_width, draw_height)`에는 `pico2dClip` 값을 사용합니다.

발밑 게임 좌표를 `(gx, gy)`, 배율을 `s`, 프레임 크기를 `(w, h)`, `pivotPixelsTopLeft`를 `(px, py)`라 하면, 그릴 중심은 `cx = gx + (w/2 - px)*s`, `cy = gy + (py - h/2)*s`입니다. 그릴 크기는 `(w*s, h*s)`입니다. 방향별 발 위치 차이를 이 기준점으로 보정합니다.

시험 배율은 0.25, 걷기 속도는 초당 8프레임으로 제안합니다. 실제 게임 화면에서 크기와 재생 속도를 조정합니다. 픽셀 스타일을 유지하려면 최근접 보간을 사용합니다. 충돌 영역은 그림 전체와 분리해 구현합니다.

걷기 시트를 준비한 단계이며 게임 연동과 실행 검증은 아직 하지 않았습니다. 섭취·공격·피격 애니메이션과 원소별 변신은 포함하지 않습니다.
