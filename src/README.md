# 1·2번 방 Python/pico2d 프로토타입

저장소 루트에서 `python main.py`로 실행합니다. 먼저 `python -m pip install -r requirements.txt`로 의존성을 설치합니다. 권장 실행 환경은 Windows 64비트 Python 3.11이며 실제 검증 환경은 Python 3.11.1입니다. 자세한 가상환경 설치는 [실행 안내](../docs/guides/LAPTOP_SETUP.md)를 참조합니다.

- `room.py`: 이동·지형·구역 진입 추격·공격 이벤트·탄환 충돌·피해/체력·넉백·처치·출구/승패
- `combat.py`: 수치 초기안과 투사체·피격 피드백 데이터. 낮은 피해 5·큰 피해 15 등은 사용자 확정값이 아님
- `elements.py`: 원천 3타/약점 1타 파괴·손상 1/2 반복·단발 방출·구슬 상태와 원소 상성
- `application.py`: pico2d 입력·창·리소스 로딩·고정 시간 간격 갱신·고정 피벗 렌더러·게임 HUD·적 HP바·Esc 메뉴
- `ui.py`: 유적 테마 HUD·초상 배지·키캡·가운데 정렬된 메뉴/승패 창. 글자 너비를 실측하며 Windows 맑은 고딕 또는 pico2d 기본 한글 글꼴 사용
- `title.py`: 이어하기/새게임 시작/종료 버튼 배치·클릭 판정·저장 유무/스테이지 표시
- `savegame.py`: 로컬 JSON 자동 저장·검증·이어하기 복원. 기본 경로 `saves/continue.json`, 검사에서는 임시 경로 주입
- `../main.py`: 실행 진입점. `../run_game.bat`은 더블클릭 실행용이며 `.venv`가 있으면 사용합니다.

좌표는 맵과 모델에서 왼쪽 위 원점·타일 단위, 그릴 때만 pico2d 왼쪽 아래 원점으로 변환합니다. 프레임 JSON의 `pico2dClip`과 `pivotPixelsTopLeft`를 사용하고 모든 프레임의 공통 배율을 유지합니다. 실행 위치와 관계없이 코드 기준으로 저장소 리소스를 찾습니다. 게임 실행에는 Pillow나 Node가 필요 없습니다.

타이틀에서 마우스/좌우 선택으로 새 게임 또는 이어하기를 실행합니다. Esc 메뉴는 저장 후 타이틀 복귀를 지원합니다. 저장 버전 2는 1·2번 방의 위치/HP/적/탄환/공격·원천·보관함·섭취 도중 상태를 복원하고 버전 1 첫 방 저장도 읽습니다.

첫 방 전투/출구에서 두 번째 방으로 전환합니다. 두 번째 방은 무속성 2·불 2, 물 원천 공격→구슬 F 섭취→물 보관/외형/Space 공격→R 자가 회복을 구현했습니다. Q/E는 보유 종류만 선택하고 Space는 소모하지 않으며 R 성공만 물 1개를 소모합니다. 무속성 적은 모든 공격에 큰 피해, 원소 적은 기존 상성 및 낮은 무속성 피해를 적용합니다. 두 번째 방 출구가 현재 구현 분량의 끝입니다. 3번 이후·다른 원소 획득/R·퍼즐·보스·지형 피해는 미구현이며 낙하/가시는 피해 없는 시안입니다.

검사: 루트에서 `python -m unittest discover -s tests -v`. 실제 SDL 창 검사: `python tools/smoke_room_01.py`, `python tools/smoke_title.py`, `python tools/smoke_room_02.py`. 마지막 검사는 손상 두 단계 각각의 실제 렌더링 픽셀 변화·바닥 접점 고정·F/R·물/불 전투·방 전환·섭취 도중 저장/이어하기를 확인합니다. 검사 저장은 임시 경로를 사용합니다.
