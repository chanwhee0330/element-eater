# 원소 오브젝트 상태 기반 파괴 · v2

사용자가 2026-11-06 확정한 변경입니다.

- 상성 불일치 공격은 종류·무속성과 관계없이 세 번에 파괴합니다. 첫 공격은 손상 1, 두 번째는 손상 2 상태입니다.
- 약점 원소 공격은 남은 내구도와 관계없이 한 번에 파괴합니다.
- 물 오브젝트의 약점은 번개, 불은 물, 바람은 불, 흙은 바람, 번개는 흙입니다.
- 손상 1·2 상태는 다음 공격까지 무기한 유지합니다. 시간만으로 다음 파손 단계가 실행되거나 원상 복구·소멸하지 않습니다.
- 파괴·방출 애니메이션은 내구도 0에서만 한 번 실행합니다. 마지막 프레임을 없애지 않고 구슬 상태로 전환해 섭취될 때까지 유지하는 구조입니다.
- 방출 완료 구슬은 다섯 종류 모두 동일한 표시 크기입니다. 이 시안은 96×96px이며, 모든 원소에 같은 규격을 적용합니다.

오브젝트 전용 내구도 규칙입니다. 약점 불일치 공격을 차단하는 적 전투 규칙과 혼동하지 않습니다. 단, 적 전투와 공유하는 상성 방향은 유지합니다.

## 파일

- `preview.html`: 오프라인 직접 공격 미리보기. 기본은 수동 모드이며, 공격 원소 선택·전체/개별 공격·약점 공격·복구·일시정지와 단발 자동 시연을 제공합니다. 시연 완료 후에도 구슬이 남습니다.
- `comparison.gif`: 위쪽 상성 불일치 3회, 아래쪽 약점 1회를 비교합니다. GIF 파일만 비교 편의를 위해 반복됩니다.
- `sprites/*-break.png`: 256×256px 8프레임 투명 시트. 손상 상태와 파괴 동작을 분리해 사용합니다.
- `sprites/*-idle.png`: 기존 대기 애니메이션 시트. 정상 상태의 대기 동작을 유지합니다.
- `sprites/*-orb.png`: 같은 96×96px 크기로 정렬한 방출 구슬.
- `animations.json`: 상태별 프레임·유지 조건·파괴 시간과 상성 데이터.
- `state-machine.mjs`: 미리보기에서 실제 사용하는 상태 전이 코드. `attack(element)`에서만 내구도가 감소하고 `update(dt)`는 파괴 후 방출만 진행합니다.

원화는 이전 버전에서 내장 image_gen으로 생성한 이미지를 재사용했습니다. 이번 변경은 상태 전이·표시 크기·프레임 패킹·미리보기 구성입니다. 원본 그림이나 기존 v1 에셋을 덮어쓰지 않았습니다.

Python/pico2d 본게임의 전투·충돌·구슬 섭취 연결은 아직 하지 않았습니다. 본게임 구현 시 `orb` 상태에서 F 섭취를 처리하면 됩니다.
